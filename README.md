# AI NOW Project Documentation
## Project Topic: SmartMove Transportation Intelligence  

### Project Overview

The SmartMove Nigeria Transport Intelligence Platform (TIP) is an enterprise transportation analytics solution developed to help transportation operators transform operational data into actionable business intelligence. 
Rather than relying on fragmented reports and spreadsheets, the platform provides centralized analytics that support operational monitoring, strategic planning, and data-driven decision-making. 

### Data Sources

This primary source of Data used for this project is Transportation Operational Dataset (Sample Data) .xlsx and this is an open source data that can be freely source online as kaggle.
